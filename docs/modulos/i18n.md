# Módulo `i18n`

Nivel: trivial.
Responsabilidad: dar los textos de interfaz, los nombres de día y la descripción de los códigos WMO en cada idioma, con castellano como respaldo.

## Ficheros
- Código: `src/i18n.js`.
- Pruebas: `test/i18n.test.js`.
- Vecinos de referencia para el estilo: `src/config.js` (export de constantes y funciones puras).

## Interfaz pública

/**

/**

Claves obligatorias de `DICCIONARIOS.es` (todas con su texto en `en`):
`cargando`, `sinConexion`, `sinDatos`, `errorGenerico`, `cambiarCiudad`, `buscarCiudad`, `ciudades`, `hoy`, `sensacion`, `humedad`, `viento`, `vientoImperial`, `lluvia`, `maxima`, `minima`, `actualizado`, `noEncontrado`, `faltaLugar`.

Convención de textos (castellano / inglés):
- `cargando` = `Cargando previsión…` / `Loading forecast…`
- `sinConexion` = `Sin conexión con Open-Meteo` / `No connection to Open-Meteo`
- `sinDatos` = `sin datos` / `no data`
- `noEncontrado` = `No se encontró {lugar}` / `{lugar} not found`
- `faltaLugar` = `Indica un lugar o unas coordenadas` / `Set a place or coordinates`
- `errorGenerico` = `No se pudo cargar la previsión` / `Could not load the forecast`
- `cambiarCiudad` = `Cambiar de ciudad` / `Change city`
- `buscarCiudad` = `Ciudad de la previsión` / `Forecast city`
- `ciudades` = `Ciudades encontradas` / `Cities found`
- `hoy` = `hoy` / `today`
- `sensacion` = `sensación {n}°` / `feels like {n}°`
- `humedad` = `{n}% humedad` / `{n}% humidity`
- `viento` = `{n} km/h` / `{n} km/h`
- `vientoImperial` = `{n} mph` / `{n} mph`
- `lluvia` = `lluvia {n}%` / `rain {n}%`
- `maxima` = `máxima {n}°` / `high {n}°`
- `minima` = `mínima {n}°` / `low {n}°`
- `actualizado` = `actualizado` / `updated`

Comportamiento:
- `t(lang, clave, params)`: busca en el diccionario de `lang`; si el idioma no existe o no tiene la clave, busca en `es`; si tampoco, devuelve `clave` tal cual (marcador visible, nunca lanza).
- La sustitución recorre las claves de `params` y reemplaza todas las apariciones de `{clave}`; los marcadores sin parámetro se dejan tal cual.
- `textoWmo`: tabla de códigos WMO 0, 1, 2, 3, 45, 48, 51, 53, 55, 56, 57, 61, 63, 65, 66, 67, 71, 73, 75, 77, 80, 81, 82, 85, 86, 95, 96, 99. Códigos fuera de la tabla devuelven `t(lang, 'sinDatos')`.
- `nombreDia`: `0 → domingo`, `1 → lunes`, …, `6 → sábado`; en `en`, `Sun`…`Sat`.

## Errores
- `TypeError` en `registrarIdioma` si `codigo` no casa con `/^[a-z]{2}(-[a-z]{2})?$/` o si `diccionario` no es un objeto. Mensaje: qué argumento falló y el formato esperado.
- `RangeError` en `nombreDia` si `diaSemana` no es un entero entre 0 y 6. Mensaje: valor recibido y rango admitido.
- `t` y `textoWmo` no lanzan nunca.

## Dependencias
- Internas: ninguna.
- Externas: ninguna.

## Criterio de aceptación
1. `t('es', 'hoy')` → `'hoy'`; `t('en', 'hoy')` → `'today'`.
2. `t('es', 'sensacion', { n: 12 })` → `'sensación 12°'`.
3. `t('es', 'viento', { n: 0 })` → `'0 km/h'` (el cero no se omite); `t('en', 'vientoImperial', { n: 12 })` → `'12 mph'`.
4. `t('fr', 'hoy')` → `'hoy'` (idioma desconocido cae a `es`).
5. `t('es', 'claveInventada')` → `'claveInventada'`.
6. `registrarIdioma('fr', { hoy: `aujourd'hui` })` → `t('fr', 'hoy')` es `"aujourd'hui"` y `t('fr', 'sensacion', { n: 5 })` sigue cayendo a `'sensación 5°'`.
7. `registrarIdioma('FR', {})` → `TypeError`.
8. `registrarIdioma('pt-br', { hoy: 'hoje' })` → no lanza; `tieneIdioma('pt-br')` es `true`.
9. `textoWmo('es', 0)` → `'despejado'`; `textoWmo('es', 95)` → `'tormenta'`; `textoWmo('en', 3)` → `'overcast'`.
10. `textoWmo('es', 12345)` → `'sin datos'`; `textoWmo('en', 12345)` → `'no data'`.
11. `nombreDia('es', 1)` → `'lun'`; `nombreDia('en', 0)` → `'Sun'`.
12. `nombreDia('es', 7)` → `RangeError`; `nombreDia('es', 1.5)` → `RangeError`.
13. `t('es', 'error {x} {y}', { x: 'a' })` → `'error a {y}'` (el marcador sin parámetro no se toca).
